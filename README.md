Aplicação Web de Chat com IA para tirar dúvidas sobre treinos, nutrição esportiva e recomendar academias na cidade de Carapicuíba - SP.

## 🚀 Funcionalidades
- **Suporte Local:** Responde dúvidas de treino e limita recomendações a Carapicuíba - SP.
- **Interface Responsiva:** Tema azul marinho moderno.
- **Modo Claro / Escuro:** Alternância de tema com um clique.
- **Histórico Persistente:** Salvo automaticamente no `localStorage`.
- **Markdown & Cópia:** Respostas formatadas com botão de copiar texto.
- **Contador & Horário:** Exibe contagem total e timestamp em cada balão.

## 🛠️ Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3, JavaScript (ES6+), Marked.js
- **Back-end:** Node.js, Express, Cors, Dotenv
- **API:** OpenAI / Azure OpenAI (Modelo `gpt-5.6-luna`)
